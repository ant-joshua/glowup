# glowup-os

Monorepo for Glowup OS.

## Structure

- `docs/`: Business, product, architecture, API, AI, and delivery documentation
- `apps/web/`: Next.js fullstack app (UI + API routes)
- `packages/`: Shared packages (types, UI, auth, database, etc.)
- `infrastructure/`: IaC and deployment manifests
