# Docs

This folder contains product, business, and engineering documentation.

## Sections

- `business/`: BRD, pitch deck notes, revenue model
- `product/`: PRDs by area
- `architecture/`: ADRs and high-level system design
- `api/`: OpenAPI + Postman collections
- `ai/`: Agents, prompts, workflows, and evaluation
- `tasks/`: Roadmap, backlog, and sprint artifacts
