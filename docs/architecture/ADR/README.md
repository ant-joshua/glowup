## When to Write an ADR

Create an ADR when a decision:
- Has meaningful trade-offs (multiple viable approaches)
- Affects multiple areas (UI/API/worker/infra)
- Will be costly to change later (data models, contracts, deployment)
- Is likely to be questioned in the future (why not X?)
